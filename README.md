# Mini SaaS de Propostas (Local)

Ferramenta local para geração de propostas profissionais
utilizando Streamlit e templates DOCX.

## Objetivo
Gerar propostas padronizadas de forma rápida, sem copiar e colar.

## Stack
- Python
- Streamlit
- docxtpl
- SQLite (local)
